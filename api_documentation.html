🥻 4. Catalog Retrieval: GET /api/v1/store/products

Returns published sarees ready for online storefront display. If an item has multiple colors (e.g., Maroon Red, Royal Blue, Emerald Green), it is marked with "is_group": true and contains a variants array with color swatches and individual variant stock.

Query Parameters

Parameter Type Default Description
in_stock_only Boolean false When set to true, only returns products currently in stock (> 0).
search String (none) Case-insensitive search across saree name, fabric, or weave.

cURL Request Example

curl -X GET "https://tunes-incidence-minutes-examples.trycloudflare.com/api/v1/store/products?in_stock_only=true" \
  -H "x-api-key: sai_store_live_sec_892176"

Fetch details for an individual saree product page. Supports querying by base color family SKU (e.g. SAI-VAR-01) or by exact variant SKU (e.g. SAI-VAR-01-BLU).

📦 6. Post-Purchase Webhook: POST /api/v1/store/orders

Called by your Angular website when a customer finishes payment. The backend processes the purchase atomically across three systems:

1. Database Inventory
Decrements quantity in saree_catalog and stock_pool.
2. TallyPrime ERP
Posts Sales Voucher under active Sarees godown.
3. Google Sheets
Appends transaction row to daily sales spreadsheet.

Request Headers

Content-Type: application/json
x-api-key: sai_store_live_sec_892176

💻 7. Angular TypeScript Integration Snippet

Copy-paste ready Angular Service utilizing standard HttpClient: 

// src/app/services/saree-store.service.ts
import { Injectable } from '@angular/core';
import { HttpClient, HttpHeaders } from '@angular/common/http';
import { Observable } from 'rxjs';

@Injectable({ providedIn: 'root' })
export class SareeStoreService {
  private baseUrl = 'https://tunes-incidence-minutes-examples.trycloudflare.com/api/v1/store';
  private apiKey = 'sai_store_live_sec_892176';

  constructor(private http: HttpClient) {}

  private getHeaders(): HttpHeaders {
    return new HttpHeaders({
      'Content-Type': 'application/json',
      'x-api-key': this.apiKey
    });
  }

  /** 1. Fetch Saree Catalog */
  getProducts(): Observable<any> {
    return this.http.get(`${this.baseUrl}/products`, { headers: this.getHeaders() });
  }

  /** 2. Fetch Single Saree or Color Group by SKU */
  getProductBySku(sku: string): Observable<any> {
    return this.http.get(`${this.baseUrl}/products/${encodeURIComponent(sku)}`, { 
      headers: this.getHeaders() 
    });
  }

  /** 3. Notify Backend of Completed Checkout (Triggers Tally + Google Sheets) */
  submitOrder(orderPayload: any): Observable<any> {
    return this.http.post(`${this.baseUrl}/orders`, orderPayload, { 
      headers: this.getHeaders() 
    });
  }
}

❓ 8. Error Codes & Troubleshooting

HTTP Status Root Cause Corrective Action
401 Unauthorized Missing or wrong API key Include x-api-key: sai_store_live_sec_892176 in request headers.
400 Bad Request Empty items array or missing SKU Ensure items is a non-empty array with valid sku and quantity.
404 Not Found SKU not found in catalog Verify SKU exists against GET /api/v1/store/products.
500 Server Error Internal exception Check admin server log or open /api-test simulator to inspect stack trace.
